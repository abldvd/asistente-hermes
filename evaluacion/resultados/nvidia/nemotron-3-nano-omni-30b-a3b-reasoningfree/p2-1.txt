La compuerta programa y ejecuta automáticamente las tareas diarias (Job Hunter, noticias, resumen de correo y sugerencias de calendario).  
Cada ejecución verifica que no haya solapamientos, que la GPU no esté ocupada por juegos y que el uso de Claude no supere el 80 % antes de delegar; si las condiciones no se cumplen, retrasa o salta la tarea y avisa al usuario.  
También desactiva la tarea de Windows correspondiente para evitar ejecuciones duplicadas y registra el último ID o fecha procesada para no repetir acciones.
